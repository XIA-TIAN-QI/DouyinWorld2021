# 樱花大学 · DouyinWorld2021

一个用 Unity + 抖音 World SDK 从零程序化搭建的黄昏微缩校园世界。

> 玩家出生在校门口，门卫老陈发任务：收集 8 枚校徽。集齐触发毕业典礼（灯光秀 + 烟花）。广场边的黄思诚会陪你——**好感满档，她才会在毕业典礼那天走过来**。

## 这个仓库里有什么

- 📖 **[制作经验历程.md](./制作经验历程.md)** —— 核心文档。从场景骨架到真机调试的完整制作手记，含踩坑总结和可复用模式。
- 📋 **[校园场景说明.md](./校园场景说明.md)** —— 技术说明。场景结构、资源占用、实现关键点。
- 💻 **`Assets/Campus/Lua/`** —— 玩法逻辑（NPC 对话、好感度、收集任务、典礼、存档）。
- 🛠️ **`Assets/Editor/DouyinCampusBuilder.cs`** —— 程序化构建整个场景的 C# 脚本。
- 🔧 **`_tools/`** —— 贴图/图集生成工具（Python）。
- ✅ **`_tests/`** —— 五项 Lua 回归测试。

## 技术栈

- Unity 2021.3.14f1c1
- DouyinWorld SDK 2.21.0（抖音虚拟创作/抖音世界）
- XLua 脚本
- URP 渲染，材质用 SDK 自研 `Douyin/World/ENV/World_Lit`

## 玩法闭环

出生遇老陈发任务 → NPC 线索 → 收集 8 枚校徽（光环+区域提示）→ 交付 → 存档 → 集齐触发灯光秀+烟花 → 满好感她才走过来 → 重进不重播。
